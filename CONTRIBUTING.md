# Contributing

1. Fork the repository and create a focused branch.
2. Run `make lint`, `make typecheck`, and `make test` before opening a pull request.
3. Add tests for behavior changes.
4. Do not commit credentials, private customer data, or real recall evidence.
5. Security issues must be reported privately as described in `SECURITY.md`.
6. Keep agent tool permissions minimal. New mutation tools require a risk class, policy rule, idempotency behavior, and verification path.
